## 🧩 About

**DayZ Mod Menu** is a curated list of DayZ open-source tools:

- **Overlays** — on-screen helpers, layout notes, loot markers, map overlay
- **Quality-of-Life Helpers** — inventory notes, config manager, HUD tweaks
- **Research Notes** — survival layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

## ✨ Features

### ESP
- Loot Tracker — mark nearby loot for study routes
- Map Overlay — readable map notes on screen
- HUD Notes — status and stamina readouts for practice
- Config Profiles — switch helper presets quickly

### Wallhack
- Menu Layout — clean, resizable overlay panel
- Custom Colors — organize UI themes
- Keybind Manager — set hotkeys per module

### Aimbot
- Single-Player Notes — study mechanics offline
- Session Log — review route and timing notes
- Editor Presets — save and restore helper settings
